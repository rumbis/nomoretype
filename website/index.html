Docs

Get started in 30 seconds

01

Get a Groq API Key

Go to console.groq.com → API Keys → Create key (starts with gsk_). Free tier included.

02

Launch NoMoreType

Open the app → Settings → paste your Groq key → click Validate.

03

Transcribe a File

Go to File Transcribe → select audio/video → choose language & output → click Transcribe.

04

Or Record Your Mic

Go to Mic Transcribe → click record → speak → click stop. Result appears instantly.

05

Use the Global Hotkey

Double-tap Left Control anywhere → record → Single-tap → text auto-inserts at cursor.

06

Polish & Export

Use the Polish tab to fix grammar or translate. All transcripts save automatically in History.

🔧 Build from Source

macOS / Linux / Windows
git clone https://github.com/rumbis/nomoretype.git
cd nomoretype

# Desktop
cd electron-app && npm install && npm start

# Build installers
npm run build:mac    # DMG
npm run build:win    # NSIS
npm run build:linux  # AppImage/DEB

# Mobile
cd capacitor-app && npm install && npx cap sync
npx cap open android  # Android Studio
npx cap open ios      # Xcode
