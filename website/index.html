Documentation

Simple, powerful.
Here's how it works.

01

Get an API Key

Go to console.groq.com → API Keys → Create a new key (starts with gsk_). It's free and takes 30 seconds.

02

Launch the App

Open NoMoreType on your platform. Go to Settings → Groq API Key, paste your key, and click Validate.

03

Transcribe a File

Go to File Transcribe, select any audio/video file, choose your language and output format, click Transcribe.

04

Or Record Your Mic

Go to Mic Transcribe, click Start Recording, speak, click stop. Your transcript appears instantly.

05

YouTube & Polish

Paste a YouTube URL to download subtitles. Use the Polish & Translate tab to fix grammar or translate.

06

Save & Share

Copy to clipboard or save as a file. All transcriptions are automatically saved in History for later review.

🔧 Advanced: Build from Source

macOS / Linux / Windows 
# Clone the repository
git clone https://github.com/rumbis/nomoretype.git
cd nomoretype

# Desktop app (Electron)
cd electron-app && npm install && npm start

# Mobile app (Capacitor)
cd capacitor-app && npm install && npx cap sync

# Web app (serve locally)
cd web-app && python3 -m http.server 8080

🔧 Build for Distribution

Package installers 
cd electron-app
npm run build:mac     # DMG + ZIP (macOS)
npm run build:win     # NSIS + portable (Windows)
npm run build:linux   # AppImage + DEB (Linux)
npm run build:all     # All platforms
